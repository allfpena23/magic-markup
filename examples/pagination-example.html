🪄 Magic Markup - Pagination Examples

Complete guide to implementing pagination in your projects

📄 Demo 1: Basic Built-in Pagination

Simple pagination using Magic Markup's built-in feature.

This shows the first itemsPerPage items with a simple info message. No navigation controls.

MagicMarkup.render('#container1', data, { card: { products: { pagination: { enabled: true, itemsPerPage: 5 } } } });

🎯 Demo 2: Enhanced Pagination with Full Controls

Advanced pagination with navigation controls using a custom renderer.

Features: Previous/Next buttons, page numbers, items per page selector, and page info.

// Register the enhanced pagination renderer const paginationRenderer = createPaginationRenderer({ itemsPerPage: 10, showPageNumbers: true, showItemsPerPageSelector: true }); magicMarkup.registerRenderer('users', paginationRenderer);

📊 Demo 3: Multiple Paginated Arrays

Different pagination settings for different data types.

Shows how to configure pagination independently for multiple arrays in the same dataset.

📚 Integration Guide

Step 1: Include Magic Markup

<link rel="stylesheet" href="path/to/magic-markup.css"> <script src="path/to/magic-markup.js"></script>

Step 2: Create Enhanced Pagination Renderer

Copy the createPaginationRenderer function from this example (see source code).

Step 3: Use in Your Project

// Initialize Magic Markup const magicMarkup = new MagicMarkup('#container'); // Create and register pagination renderer const usersPagination = createPaginationRenderer({ itemsPerPage: 10, showPageNumbers: true, showItemsPerPageSelector: true }); magicMarkup.registerRenderer('users', usersPagination); // Render your data magicMarkup.render(yourData);

Configuration Options

{ itemsPerPage: 10, // Items per page (default: 10) showPageNumbers: true, // Show page number buttons (default: true) maxPageButtons: 5, // Max page buttons to show (default: 5) showItemsPerPageSelector: true, // Show items per page dropdown (default: true) itemsPerPageOptions: [5, 10, 25, 50], // Options for selector viewMode: 'table' // 'table', 'cards', or null for toggle (default: null) }
