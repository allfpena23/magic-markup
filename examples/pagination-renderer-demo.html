📖 How to Use the Custom Pagination Renderer

Step 1: Include Required Files

<!-- CSS files --> <link rel="stylesheet" href="magic-markup.css"> <link rel="stylesheet" href="renderers/pagination-renderer.css"> <!-- JavaScript files --> <script src="magic-markup.js"></script> <script src="renderers/pagination-renderer.js"></script>

Step 2: Create the Renderer

// Create pagination renderer with custom config const paginationRenderer = createPaginationRenderer({ itemsPerPage: 10, showPageNumbers: true, maxPageButtons: 7, showItemsPerPageSelector: true, itemsPerPageOptions: [5, 10, 25, 50, 100], viewMode: null // null = toggle, 'table' or 'cards' });

Step 3: Register and Use the Renderer

// Register the custom renderer MagicMarkup.registerRenderer('products', paginationRenderer); // Render your data const data = { products: [ { id: 1, name: "Product 1", price: 29.99, stock: 100 }, { id: 2, name: "Product 2", price: 39.99, stock: 50 }, // ... more products ] }; MagicMarkup.render('#container', data);

Configuration Options

Option Type Default Description
itemsPerPage Number 10 Number of items to display per page
showPageNumbers Boolean true Show page number buttons
maxPageButtons Number 7 Maximum number of page buttons to show
showItemsPerPageSelector Boolean true Show items per page dropdown
itemsPerPageOptions Array [5, 10, 25, 50, 100] Options for items per page selector
viewMode String null null (toggle), 'table', or 'cards'
