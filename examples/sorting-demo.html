🔄 Column Sorting Demo

Click on any column header to sort the table

How to Use Column Sorting:

  • Click a column header to sort by that column in ascending order
  • Click again to toggle between ascending (▲) and descending (▼) order
  • The sorted column will be highlighted in blue
  • Sorting works intelligently based on data type:
    • Numbers are sorted numerically
    • Dates are sorted chronologically
    • Strings are sorted alphabetically (case-insensitive)
    • Booleans are sorted with true values first
  • To disable sorting, set sorting: { enabled: false } in the configuration
