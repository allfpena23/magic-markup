🎯 Alignment Test

This example demonstrates the automatic and custom alignment features:

  • Automatic Alignment:
    • Numbers (age, salary, score) → Right-aligned
    • Strings (name, department, email) → Left-aligned
    • Booleans (active, verified) → Center-aligned
    • Dates (joinDate) → Center-aligned
  • Custom Alignment Override:
    • department → Forced to CENTER using Align.CENTER
    • email → Forced to RIGHT using Align.RIGHT
