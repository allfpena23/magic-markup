Complete guide to implementing pagination in your projects

📄 Demo 1: Basic Built-in Pagination

Simple pagination using Magic Markup's built-in feature.

This shows the first itemsPerPage items with an info message. Perfect for simple use cases.

MagicMarkup.render('#container', data, { card: { products: { pagination: { enabled: true, itemsPerPage: 5 } } } });

📊 Demo 2: Different Page Sizes

Multiple datasets with different pagination settings.

Shows how to configure different itemsPerPage values for different data types.

MagicMarkup.render('#container', data, { card: { users: { pagination: { enabled: true, itemsPerPage: 3 } }, orders: { pagination: { enabled: true, itemsPerPage: 10 } } } });

📚 How to Use Pagination in Your Project

Step 1: Include Magic Markup

<link rel="stylesheet" href="path/to/magic-markup.css"> <script src="path/to/magic-markup.js"></script>

Step 2: Configure Pagination

// Your data const data = { products: [ { id: 1, name: "Product 1", price: 29.99 }, { id: 2, name: "Product 2", price: 39.99 }, // ... more products ] }; // Render with pagination MagicMarkup.render('#container', data, { showHeader: false, showStats: false, card: { products: { pagination: { enabled: true, itemsPerPage: 10 // Show 10 items per page }, header: 'name' // Use 'name' field for card headers } } });

Configuration Options

Pagination Configuration:

  • enabled - Set to true to enable pagination
  • itemsPerPage - Number of items to display per page (default: 10)

Note: The built-in pagination shows only the first page. For full navigation controls (previous/next buttons, page numbers), you would need to implement a custom renderer.
