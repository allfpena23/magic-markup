# Screenshots

This directory contains screenshots for the Magic Markup README.

## Required Screenshots

To complete the README documentation, please add the following screenshots:

1. **overview.png** - Full view showing primitive values with color-coded highlighting (success, critical, true/false)
2. **table-view.png** - Table view of the logs array showing color-coded severity levels (INFO, WARNING, ERROR, SUCCESS) with action buttons
3. **card-view.png** - Card layout view of the same data with action buttons
4. **nested-objects.png** - Collapsed/expanded accordion views showing nested objects and arrays

## How to Capture Screenshots

1. Open `examples/basic-example.html` in your browser
2. Use your browser's screenshot tool or a tool like:
   - Windows: Snipping Tool or Win + Shift + S
   - Mac: Cmd + Shift + 4
   - Browser DevTools: Cmd/Ctrl + Shift + P → "Capture screenshot"
3. Save screenshots with the exact filenames listed above
4. Recommended dimensions: 1200px wide (or full width of the rendered content)

## Screenshot Guidelines

- Use the basic-example.html for consistency
- Capture at a reasonable zoom level (100% or 125%)
- Include enough context to show the feature clearly
- Ensure text is readable
- Keep file sizes reasonable (< 500KB per image)
